# C++ Practice Repository

This repository contains my C++ practice programs that I learned during my college classes. It is not a single project but a collection of programs covering different C++ concepts.

The purpose of this repository is to:
- Practice C++ programming
- Understand Object-Oriented Programming (OOP)
- Learn different C++ concepts through examples
- Keep all classroom exercises in one place

## Topics Covered

- Basic C++ Programs
- Input & Output
- Variables and Data Types
- Operators
- Conditional Statements
- Loops
- Functions
- Arrays
- Strings
- Structures
- Classes & Objects
- Constructors
- Destructor
- Function Overloading
- Operator Overloading
- Inheritance
- Polymorphism
- Virtual Functions
- Abstract Classes
- File Handling
- Dynamic Memory Allocation
- Templates
- Exception Handling

## How to Run

Compile using g++:

```bash
g++ filename.cpp -o program
```

Run:

```bash
./program
```

On Windows:

```bash
program.exe
```
